      <h2 id="useReactPaint">useReactPaint Hook</h2>
      <p>
        The core hook: it creates a canvas, with its state and its logic, and returns its handle.
      </p>

          </tr>
        </thead>
        <tbody>
          <tr>
            <td><code>width</code></td>
            <td><code>number</code></td>
            <td>Canvas width in pixels</td>
            <td><code>1000</code></td>
          </tr>
          <tr>
            <td><code>height</code></td>
            <td><code>number</code></td>

          </tr>
          <tr>
            <td><code>mode</code></td>
            <td><code>'editor' | 'viewer'</code></td>
            <td>Editor mode: <code>'editor'</code> enables full interaction, <code>'viewer'</code> makes canvas read-only</td>

      <p>
        The props are compared by value: <code>options</code> can be written inline. <code>shapes</code> is only read when the canvas is created, and by <code>clearCallback: 'defaultShapes'</code>.
      </p>

      <h3>Return Value</h3>
      <p>
        The hook returns a handle, <code>paint</code>, of type <code>ReactPaint</code>, to give to the <code>Editor</code> and <code>Canvas</code> components, or to your own editor.
        Its identity never changes, and the component calling the hook does not render again when the state changes: read the state with <a href="#usePaintState" target="_self"><code>usePaintState</code></a>.
      </p>
      <Source language='typescript' code={`type ReactPaint = {
  actions: EditorActions
  getState: () => EditorState
  subscribe: (listener: () => void) => () => void
  registerEvent: <E extends ReactPaintEventName>(event: E, fn: ReactPaintEvents[E]) => () => void
  unregisterEvent: <E extends ReactPaintEventName>(event: E, fn?: ReactPaintEvents[E]) => void
  resetCanvas: (shapes?: DrawableShape[], clearHistory?: boolean) => void
  getCurrentImage: (view: ExportView) => string
  getCurrentData: () => StateData
  editorRef: (element: HTMLElement | null) => void
}`} />
      <ul>
        <li><code>actions</code> - Commands to act on the canvas (see below). Their identity never changes</li>
        <li><code>getState()</code> - The current state (see below), without subscription: to read in event handlers. The same object is returned as long as nothing changes</li>
        <li><code>subscribe(listener)</code> - Calls the listener after each change of the state, and returns the function that unsubscribes it</li>
        <li><code>registerEvent</code>, <code>unregisterEvent</code>, <code>resetCanvas</code>, <code>getCurrentImage</code>, <code>getCurrentData</code> - See <a href="#Methods" target="_self">Methods</a></li>
        <li><code>editorRef</code> - Callback ref to set on the root element of a custom editor. It defines the area where interactions and keyboard shortcuts are active. The <code>Editor</code> component sets it</li>
      </ul>

      <h4>State</h4>
      <p>The <code>EditorState</code> returned by <code>getState</code> and <code>usePaintState</code>. Each slice keeps its identity while it does not change.</p>
      <ul>
        <li><code>mode</code>, <code>disabled</code> - Values given to the hook</li>
        <li><code>features</code> - <code>{'{ edition: boolean; zoom: boolean }'}</code></li>
        <li><code>width</code>, <code>height</code> - Logical canvas size</li>
        <li><code>layout</code> - <code>{"{ size: 'fixed' | 'infinite'; canGrow: boolean; canShrink: boolean }"}</code></li>
        <li><code>view</code> - <code>{'{ zoom, offset, displayWidth, displayHeight, scaleRatio }'}</code></li>
        <li><code>gridGap</code> - Current grid gap</li>
        <li><code>shapes</code> - All shapes, from top to bottom</li>
        <li><code>selection</code> - Selected shape, or group of shapes when several are selected</li>
        <li><code>selectedShapes</code> - Selected shapes as an array</li>
        <li><code>selectedShapeIds</code> - Ids of the selected shapes, to give to the actions. The array keeps its identity while the same shapes are selected</li>
        <li><code>activeTool</code>, <code>tools</code> - Active tool (the selection tool, the move tool or one of the tools, kept up to date with them) and available drawing tools</li>
        <li><code>history</code> - <code>{'{ canUndo: boolean; canRedo: boolean; canClear: boolean }'}</code></li>
        <li><code>clipboard</code> - <code>{'{ hasContent: boolean }'}</code></li>
        <li><code>withContextMenu</code> - Whether the context menu is enabled</li>
        <li><code>interaction</code> - <code>{'{ mode, hoveredShape, selectionFrame, modifiers: { shift, alt, space }, isPanning, focus: { component, canvas } }'}</code>. It changes on each move of the pointer</li>
        <li><code>contextMenu</code> - <code>{'{ shapes, anchorIndex, canRemoveAnchor, canvasPosition, clientPosition }'}</code> when the context menu is open. <code>canRemoveAnchor</code> tells whether the point under the cursor can be removed with <code>removeShapePoint</code>, <code>undefined</code> otherwise</li>
      </ul>

      <h4>Actions</h4>
      <ul>
        <li><code>selectTool(toolOrId)</code> - Selects the selection tool, the move tool or one of the tools, found by id. An unknown tool is ignored</li>
        <li><code>updateToolSettings(toolId, field, value)</code></li>
        <li><code>selectShapes(ids)</code>, <code>selectAllShapes()</code>, <code>clearSelection()</code></li>
        <li><code>removeShapes(ids)</code>, <code>duplicateShapes(ids, {'{ translate?, select? }'})</code></li>
        <li><code>moveShapes(ids, 'first' | 'last' | 'forward' | 'backward')</code>, <code>swapShapes(firstId, secondId)</code></li>
        <li><code>toggleShapesVisibility(ids)</code>, <code>toggleShapesLock(ids)</code> - Toggle each shape</li>
        <li><code>setShapesVisibility(ids, visible)</code>, <code>setShapesLocked(ids, locked)</code> - Set the same value on all shapes</li>
        <li><code>updateShapesStyle(ids, field, value, {'{ save? }'})</code> - Updates a style field. Text size is recomputed when changing the font</li>
        <li><code>transformShapes(ids, 'flipHorizontally' | 'flipVertically' | 'rotateClockwise' | 'rotateCounterclockwise')</code></li>
        <li><code>removeShapePoint(id, pointIndex)</code> - Removes a point of a polygon or a curve, which keep at least 2 points</li>
        <li><code>addPicture(fileOrUrl, {'{ maxWidth?, maxHeight?, select? }'})</code></li>
        <li><code>copy(ids?)</code>, <code>cut(ids?)</code>, <code>paste()</code> - Use the selection when no ids are given</li>
        <li><code>undo()</code>, <code>redo()</code>, <code>saveShapes()</code> - <code>saveShapes</code> adds the current state to the history, after updates made with <code>{'{ save: false }'}</code></li>
        <li><code>clearCanvas()</code>, <code>loadFile(file)</code>, <code>exportPicture(view)</code>, <code>exportData()</code></li>
        <li><code>setZoom('zoom' | 'unzoom' | 'default')</code>, <code>resetZoom()</code> - Zoom in, out, or back to 100%</li>
        <li><code>setOffset(offset)</code> - Moves the view to the <code>Point</code> <code>[x, y]</code>. The offset is kept inside the canvas when its size is fixed</li>
        <li><code>setGridGap(gap)</code></li>
        <li><code>closeContextMenu()</code></li>
      </ul>

        See the <LinkTo title='React Paint/Custom editor' story='docs'>Custom editor</LinkTo> story for a complete example.
      </p>

      <h2 id="usePaintState">usePaintState Hook</h2>
      <p>
        Reads the state during a render, and renders the component again only when the selected value changes.
      </p>
      <Source language='typescript' code={`usePaintState(paint: ReactPaint): EditorState
usePaintState<T>(paint: ReactPaint, selector: (state: EditorState) => T, isEqual?: (a: T, b: T) => boolean): T`} />
      <ul>
        <li><code>selector</code> - Picks a value in the state. Without selector, the whole state is returned, and the component renders on each change</li>
        <li><code>isEqual</code> - Compares the previous and the new value (default: <code>Object.is</code>). An equal value keeps its identity</li>
      </ul>
      <Source language='typescript' code={`import { shallowEqual, usePaintState } from '@yorab/react-paint'

const canUndo = usePaintState(paint, state => state.history.canUndo)
const view = usePaintState(paint, state => state.view)
// a selector building an object or an array needs an equality function
const { shapes, selectedShapes } = usePaintState(paint, state => ({ shapes: state.shapes, selectedShapes: state.selectedShapes }), shallowEqual)`} />
      <p>
        <code>shallowEqual(a, b)</code> compares two values, and the first level of two objects or arrays, with <code>Object.is</code>.
        In development, a warning is logged when a selector returns a new value on each call without an equality function telling they are equal.
      </p>

      <h2 id="PaintProvider">PaintProvider and usePaint</h2>
      <p>
        <code>PaintProvider</code> gives a handle to the components below it, which read it with <code>usePaint()</code>, without passing it through props.
        The <code>Editor</code> component provides it to its children. Use it to place parts of your interface, like a toolbar, outside of the editor.
      </p>
      <Source language='typescript' code={`const UndoButton = () => {
  const paint = usePaint()
  const canUndo = usePaintState(paint, state => state.history.canUndo)
  return <button disabled={!canUndo} onClick={paint.actions.undo}>Undo</button>
}

const App = () => {
  const paint = useReactPaint()
  return (
    <PaintProvider paint={paint}>
      <UndoButton />
      <Editor paint={paint}>
        <Canvas paint={paint} />
      </Editor>
    </PaintProvider>
  )
}`} />
      <p>
        See the <LinkTo title='React Paint/External toolbar' story='docs'>External toolbar</LinkTo> story.
      </p>

      <h2 id="Events">Events</h2>
      <p>
        React Paint emits events that you can listen to using <code>paint.registerEvent</code> and <code>paint.unregisterEvent</code>.
        They are emitted right after the change of the state, before React renders it.
      </p>

      <h3>dataChanged</h3>
      <p>
        Fired whenever the canvas state changes (shapes added, removed, or modified).
      </p>
      <Source language='typescript' code={`paint.registerEvent('dataChanged', (data: StateData, source: 'user' | 'remote') => {
  // data.shapes contains all current shapes
  // source indicates if change came from user interaction ('user') or remote update ('remote')
  console.log('Canvas data changed:', data)
})`} />

      <table>
        <thead>
          <tr>
            <th>Parameter</th>

      <h2 id="Performance">Performance</h2>
      <p>
        The component calling <code>useReactPaint</code> never renders again because of the drawing: the components that read the state with <code>usePaintState</code> do, when the value they select changes.
        The gestures on the canvas (hover, drag, selection frame, pan, brush) are drawn without rendering the <code>Canvas</code> component.
      </p>
      <ul>
        <li>Select precise slices of the state: a component reading <code>state.history.canUndo</code> does not render while a shape is dragged, one reading <code>state.shapes</code> does</li>
        <li>When a selector builds an object or an array, give <code>shallowEqual</code> (or your own equality function), otherwise the component renders on each change of the state</li>
        <li>Read <code>state.interaction</code> only when you need it: it changes on each move of the pointer</li>
        <li>In event handlers, read the state with <code>paint.getState()</code> instead of subscribing to it</li>
      </ul>
