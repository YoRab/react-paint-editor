      <h2 id="useReactPaint">useReactPaint Hook</h2>
      <p>
        The core hook: it creates a canvas, with its state and its logic, and returns its handle.
      </p>

        <tbody>
          <tr>

            <td><code>number</code></td>
            <td>Canvas width in pixels</td>
            <td><code>1000</code></td>

      <p>
        The props are compared by value: <code>options</code> can be written inline. <code>shapes</code> is only read when the canvas is created, and by <code>clearCallback: 'defaultShapes'</code>.
      </p>

      <h3>Return Value</h3>
      <p>
        The hook returns a handle, <code>paint</code>, of type <code>ReactPaint</code>, to give to the <code>Editor</code> and <code>Canvas</code> components, or to your own editor.
        Its identity never changes, and the component calling the hook does not render again when the state changes: read the state with <a href="#usePaintState" target="_self"><code>usePaintState</code></a>.
      </p>
      <Source language='typescript' code={`type ReactPaint = {
  actions: EditorActions
  getState: () => EditorState
  subscribe: (listener: () => void) => () => void
  registerEvent: <E extends ReactPaintEventName>(event: E, fn: ReactPaintEvents[E]) => () => void
  unregisterEvent: <E extends ReactPaintEventName>(event: E, fn?: ReactPaintEvents[E]) => void
  batch: <R>(fn: () => R) => R
  getShape: (id: string) => ShapeEntity | undefined
  getBounds: (ids: string[]) => ShapesBounds | undefined
  getShapesAt: (point: Point) => ShapeEntity[]
  toCanvasPosition: (clientPosition: { x: number; y: number }) => Point | undefined
  toClientPosition: (point: Point) => { x: number; y: number } | undefined
  resetCanvas: (shapes?: ShapeInput[], clearHistory?: boolean) => void
  getCurrentImage: (options?: ExportImageOptions) => string
  getCurrentData: () => StateData
  scopeRef: (element: HTMLElement | null) => void
}`} />
      <ul>
        <li><code>actions</code> - Commands to act on the canvas (see below). Their identity never changes</li>
        <li><code>getState()</code> - The current state (see below), without subscription: to read in event handlers. The same object is returned as long as nothing changes</li>
        <li><code>subscribe(listener)</code> - Calls the listener after each change of the state, and returns the function that unsubscribes it</li>
        <li><code>registerEvent</code>, <code>unregisterEvent</code>, <code>batch</code>, <code>getShape</code>, <code>getBounds</code>, <code>getShapesAt</code>, <code>toCanvasPosition</code>, <code>toClientPosition</code>, <code>resetCanvas</code>, <code>getCurrentImage</code>, <code>getCurrentData</code> - See <a href="#Methods" target="_self">Methods</a></li>
        <li><code>scopeRef</code> - Callback ref defining the area where keyboard shortcuts are active, the canvas by default. The pointer always works over the canvas. Set it on the root element of a custom editor so that the shortcuts also work while its toolbar is focused. The <code>Editor</code> component sets it</li>
      </ul>

      <h4>State</h4>
      <p>The <code>EditorState</code> returned by <code>getState</code> and <code>usePaintState</code>. Each slice keeps its identity while it does not change.</p>
      <ul>
        <li><code>mode</code>, <code>disabled</code> - Values given to the hook</li>
        <li><code>features</code> - <code>{'{ edition: boolean; zoom: boolean }'}</code></li>
        <li><code>width</code>, <code>height</code> - Logical size of the drawing</li>
        <li><code>layout</code> - <code>{"{ size: 'fixed' | 'infinite'; resize: 'scaleDown' | 'scale' | 'scaleUp' | 'none' | 'extend' }"}</code></li>
        <li><code>view</code> - <code>{'{ zoom, offset, displayWidth, displayHeight, scaleRatio, visibleArea }'}</code>. A point of the drawing is displayed at <code>(point + offset) × scaleRatio</code> pixels from the top left corner of the canvas. <code>visibleArea</code> is the part of the drawing displayed, as a <code>Rect</code> in its units: it goes beyond a fixed drawing smaller than the view</li>
        <li><code>options</code> - Options in effect: the options of the hook with the overrides of <code>setOptions</code> and their defaults, without the functions (<code>clearCallback</code>, <code>resolvePictureSrc</code>). The grid and the default styles of the tools changed while editing are in <code>gridGap</code> and <code>tools</code></li>
        <li><code>gridGap</code> - Current grid gap</li>
        <li><code>shapes</code> - All shapes, from top to bottom</li>
        <li><code>selection</code> - Selected shape, or group of shapes when several are selected</li>
        <li><code>selectedShapes</code> - Selected shapes as an array</li>
        <li><code>selectedShapeIds</code> - Ids of the selected shapes, to give to the actions. The array keeps its identity while the same shapes are selected</li>
        <li><code>activeTool</code>, <code>tools</code> - Active tool (the selection tool, the move tool or one of the tools, kept up to date with them) and available drawing tools</li>
        <li><code>history</code> - <code>{'{ canUndo: boolean; canRedo: boolean; canClear: boolean }'}</code></li>
        <li><code>clipboard</code> - <code>{'{ hasContent: boolean }'}</code></li>
        <li><code>withContextMenu</code> - Whether the context menu is enabled</li>
        <li><code>withDropPicture</code> - Whether the image files dropped on the canvas are added: the <code>withDropPicture</code> option, the edition and the picture tool are needed</li>
        <li>
          <p><code>interaction</code> - <code>{'{ mode, hoveredShape, selectionHover, selectionFrame, modifiers: { shift, alt, space }, isPanning, focus: { component, canvas } }'}</code>. It changes on each move of the pointer</p>
          <ul>
            <li><code>mode</code> - The gesture running: <code>'translate'</code>, <code>'rotate'</code>, <code>'resize'</code>, <code>'selectionFrame'</code>, <code>'brush'</code>, <code>'preview'</code> (a polygon or a curve being drawn), <code>'textedition'</code>, <code>'contextMenu'</code>, or <code>'default'</code> between them</li>
            <li><code>hoveredShape</code> - Shape under the mouse, searched between the gestures. The anchors of the selection outside of its shape are given by <code>selectionHover</code></li>
            <li><code>selectionHover</code> - Part of the selection under the pointer, which tells the gesture a press starts: <code>{"{ mode: 'translate' }"}</code> inside it, <code>{"{ mode: 'rotate' }"}</code> on the anchor of the rotation, <code>{"{ mode: 'resize', anchor }"}</code> on an anchor of the resize. The <code>anchor</code> is the index of a point of a line, a polygon or a curve, or else its place on the borders of the selection before its rotation, from <code>[0, 0]</code> (top left) to <code>[1, 1]</code> (bottom right). <code>undefined</code> away from the selection and during the gestures</li>
          </ul>
        </li>
        <li><code>contextMenu</code> - <code>{'{ shapes, anchorIndex, canRemoveAnchor, canvasPosition, clientPosition }'}</code> when the context menu is open. <code>canRemoveAnchor</code> tells whether the point under the cursor can be removed with <code>removeShapePoint</code>, <code>undefined</code> otherwise</li>
      </ul>

      <h4>Actions</h4>
      <ul>
        <li><code>selectTool(toolOrId)</code> - Selects the selection tool, the move tool or one of the tools, found by id. An unknown tool is ignored</li>
        <li><code>updateToolSettings(toolId, field, value)</code>, <code>setToolStyle(toolId, style)</code> - Default values of a tool, a field the tool has not is ignored</li>
        <li><code>selectShapes(ids, {"{ mode? }"})</code>, <code>selectAllShapes()</code>, <code>clearSelection()</code> - <code>mode</code> is <code>'replace'</code>, <code>'add'</code> or <code>'remove'</code></li>
        <li><code>addShapes(shapes, {'{ select?, index?, save?, source? }'})</code>, <code>updateShapes(patches, {'{ updateTool?, save?, source? }'})</code> - See <a href="#Actions" target="_self">Driving the canvas from the code</a></li>
        <li><code>removeShapes(ids)</code>, <code>duplicateShapes(ids, {'{ translate?, select? }'})</code></li>
        <li><code>translateShapes(ids, [dx, dy])</code>, <code>rotateShapes(ids, angle, {'{ center? }'})</code>, <code>resizeShapes(ids, box)</code></li>
        <li><code>moveShapes(ids, 'first' | 'last' | 'forward' | 'backward')</code>, <code>swapShapes(firstId, secondId)</code>, <code>setShapeIndex(id, index)</code>, <code>reorderShapes(ids)</code></li>
        <li><code>toggleShapesVisibility(ids)</code>, <code>toggleShapesLock(ids)</code> - Toggle each shape</li>
        <li><code>setShapesVisibility(ids, visible)</code>, <code>setShapesLocked(ids, locked)</code> - Set the same value on all shapes</li>
        <li><code>setShapesStyle(ids, style, {'{ updateTool?, save? }'})</code>, <code>updateShapesStyle(ids, field, value, {'{ save? }'})</code> - Updates style fields. Text size is recomputed when changing the font</li>
        <li><code>transformShapes(ids, 'flipHorizontally' | 'flipVertically' | 'rotateClockwise' | 'rotateCounterclockwise')</code></li>
        <li><code>insertShapePoint(id, index, point)</code>, <code>moveShapePoint(id, index, point)</code>, <code>removeShapePoint(id, pointIndex)</code> - Points of a line, a polygon or a curve, which keep at least 2 points</li>
        <li><code>editText(id)</code> - Opens the edition box of a text</li>
        <li><code>addPicture(fileOrUrl, {'{ maxWidth?, maxHeight?, select?, position? }'})</code> - adds the picture at the center of the visible area, or centered on <code>position</code> (in the units of the drawing)</li>
        <li><code>copy(ids?)</code>, <code>cut(ids?)</code>, <code>paste()</code> - Use the selection when no ids are given</li>
        <li><code>undo()</code>, <code>redo()</code>, <code>saveShapes()</code> - <code>saveShapes</code> adds the current state to the history, after updates made with <code>{'{ save: false }'}</code></li>
        <li><code>clearCanvas()</code>, <code>loadFile(file)</code>, <code>loadData(data)</code>, <code>exportPicture(options)</code>, <code>exportData(options)</code></li>
        <li><code>setZoom('zoom' | 'unzoom' | 'default')</code>, <code>zoomTo(level, {'{ center? }'})</code>, <code>resetZoom()</code> - Zoom in, out (to the next of the <code>ZOOM_LEVELS</code>), to a level, or back to 100%. The zoom stays between the first and the last <code>ZOOM_LEVELS</code></li>
        <li><code>zoomToShapes(ids?, {'{ padding? }'})</code> - Zooms and scrolls so that the shapes fill the view, all the visible shapes by default. The padding is in pixels of the screen</li>
        <li><code>setOffset(offset)</code>, <code>panBy([dx, dy])</code> - Moves the view. The offset is kept inside the drawing when its size is fixed</li>
        <li><code>setGridGap(gap)</code> - See <code>GRID_PRESETS</code></li>
        <li><code>openContextMenu({'{ clientPosition, canvasPosition?, ids? }'})</code>, <code>closeContextMenu()</code></li>
        <li><code>setOptions(options)</code>, <code>resetOptions()</code>, <code>resetSettings()</code></li>
      </ul>

        See the <LinkTo title='React Paint/Custom editor' story='docs'>Custom editor</LinkTo> story for a complete example.

      <h2 id="usePaintState">usePaintState Hook</h2>
      <p>
        Reads the state during a render, and renders the component again only when the selected value changes.
      </p>
      <Source language='typescript' code={`usePaintState(paint: ReactPaint): EditorState
usePaintState<T>(paint: ReactPaint, selector: (state: EditorState) => T, isEqual?: (a: T, b: T) => boolean): T`} />
      <ul>
        <li><code>selector</code> - Picks a value in the state. Without selector, the whole state is returned, and the component renders on each change</li>
        <li><code>isEqual</code> - Compares the previous and the new value (default: <code>Object.is</code>). An equal value keeps its identity</li>
      </ul>
      <Source language='typescript' code={`import { shallowEqual, usePaintState } from '@yorab/react-paint'

const canUndo = usePaintState(paint, state => state.history.canUndo)
const view = usePaintState(paint, state => state.view)
// a selector building an object or an array needs an equality function
const { shapes, selectedShapes } = usePaintState(paint, state => ({ shapes: state.shapes, selectedShapes: state.selectedShapes }), shallowEqual)`} />
      <p>
        <code>shallowEqual(a, b)</code> compares two values, and the first level of two objects or arrays, with <code>Object.is</code>.
        In development, a warning is logged when a selector returns a new value on each call without an equality function telling they are equal.
      </p>

      <h2 id="PaintProvider">PaintProvider and usePaint</h2>
      <p>
        <code>PaintProvider</code> gives a handle to the components below it, which read it with <code>usePaint()</code>, without passing it through props.
        The <code>Editor</code> component provides it to its children. Use it to place parts of your interface, like a toolbar, outside of the editor.
      </p>
      <Source language='typescript' code={`const UndoButton = () => {
  const paint = usePaint()
  const canUndo = usePaintState(paint, state => state.history.canUndo)
  return <button disabled={!canUndo} onClick={paint.actions.undo}>Undo</button>
}

const App = () => {
  const paint = useReactPaint()
  return (
    <PaintProvider paint={paint}>
      <UndoButton />
      <Editor paint={paint}>
        <Canvas paint={paint} />
      </Editor>
    </PaintProvider>
  )
}`} />
      <p>
        See the <LinkTo title='React Paint/External toolbar' story='docs'>External toolbar</LinkTo> story.
      </p>

      <h2 id="Events">Events</h2>
      <p>
        React Paint emits events that you can listen to using <code>paint.registerEvent</code> and <code>paint.unregisterEvent</code>.
        They are emitted right after the change of the state, before React renders it.
      </p>

      <h3>dataChanged</h3>
      <p>
        Fired whenever the canvas state changes (shapes added, removed, or modified).
      </p>
      <Source language='typescript' code={`paint.registerEvent('dataChanged', (data: StateData, source: 'user' | 'remote', changes: DataChanges) => {
  // data.shapes contains all current shapes
  // source indicates if change came from user interaction ('user') or remote update ('remote')
  // changes.added, changes.updated and changes.removed contain only the shapes which changed
  console.log('Canvas data changed:', data, changes)
})`} />

      <table>
        <thead>
          <tr>
            <th>Parameter</th>
            <th>Type</th>
            <th>Description</th>
          </tr>
        </thead>
        <tbody>
          <tr>
            <td><code>data</code></td>
            <td><code>StateData</code></td>
            <td>Current canvas state containing shapes and config</td>
          </tr>
          <tr>
            <td><code>source</code></td>
            <td><code>'user' | 'remote'</code></td>
            <td>Origin of the change: <code>'user'</code> for local interactions and actions, <code>'remote'</code> for loaded data, undo / redo, and actions given <code>{`{ source: 'remote' }`}</code></td>
          </tr>
          <tr>
            <td><code>changes</code></td>
            <td><code>DataChanges</code></td>
            <td>Shapes changed since the previous state, in the format of <code>data.shapes</code>: <code>added</code>, <code>updated</code> as <code>{`{ shape, previous }`}</code>, <code>removed</code>, and <code>reordered</code> when the shapes still there are in another order. An undo gives the reverse changes</td>
          </tr>
        </tbody>
      </table>
      <p>The data are only built while a listener is registered: the pictures are encoded in them. The changes allow to send only what changed to a server: a shape is only given as updated when its exported data differ.</p>

      <h3>selectionChanged</h3>
      <p>
        Fired when the set of selected shapes changes. It is not fired when the selected shapes are only modified (moved, resized, restyled...).
      </p>
      <Source language='typescript' code={`paint.registerEvent('selectionChanged', (selectedShapes: ShapeEntity[]) => {
  console.log('Selected shapes:', selectedShapes.map(shape => shape.id))
})`} />

      <h3>toolChanged</h3>
      <p>
        Fired when the active tool changes.
      </p>
      <Source language='typescript' code={`paint.registerEvent('toolChanged', (tool: ToolsType) => {
  console.log('Active tool:', tool.id)
})`} />

      <h3>shapeClicked and shapeHovered</h3>
      <p>
        Fired when a visible shape is clicked, and when the pointer enters a shape or leaves it (<code>undefined</code>). They are also fired in viewer mode, where the cursor shows the clickable shapes, and for locked shapes.
        The shapes under the pointer are only searched while one of these events is listened.
      </p>
      <Source language='typescript' code={`paint.registerEvent('shapeClicked', (shape: ShapeEntity, info: ShapePointerInfo) => {
  // info.canvasPosition: position in the drawing, info.clientPosition: position in the viewport
  openComment(shape.id, shape.data, info.clientPosition)
})
paint.registerEvent('shapeHovered', (shape: ShapeEntity | undefined) => setHighlighted(shape?.id))`} />

      <h3>canvasClicked and canvasDoubleClicked</h3>
      <p>
        Fired when the drawing is clicked, on a visible shape (locked ones included) or on an empty area (<code>undefined</code>), in every mode: while editing, a click which draws a shape is also a <code>canvasClicked</code>.
        A second click at the same place soon after the first one fires <code>canvasDoubleClicked</code>, after its <code>canvasClicked</code>. A click outside of a fixed drawing smaller than the view fires nothing.
      </p>
      <Source language='typescript' code={`paint.registerEvent('canvasClicked', (shape: ShapeEntity | undefined, info: ShapePointerInfo) => {
  // in viewer mode, a click on an empty area adds a pin at this point of the drawing
  if (!shape) addPin(info.canvasPosition)
})
paint.registerEvent('canvasDoubleClicked', (shape: ShapeEntity | undefined) => shape && openDetails(shape.id))`} />

      <h3>pictureDropFailed</h3>
      <p>
        Fired for each file dropped on the canvas which is not added as a picture (see the <code>withDropPicture</code> option): its type is not an accepted image, or the image cannot be loaded. The Editor shows an error message for it.
      </p>
      <Source language='typescript' code={`paint.registerEvent('pictureDropFailed', (file: File, error: unknown) => {
  console.warn('Cannot add', file.name, error)
})`} />

      <h3>pictureLoaded and pictureLoadFailed</h3>
      <p>
        <code>pictureLoaded</code> is fired when a picture added by <code>addShapes</code>, or whose source is changed by <code>updateShapes</code>, is loaded and drawn: the actions return before the image is loaded.
        The pictures of loaded data (<code>loadData</code>, <code>loadFile</code>, <code>resetCanvas</code>, the <code>shapes</code> of the hook) are loaded before the drawing is shown.
      </p>
      <p>
        <code>pictureLoadFailed</code> is fired when the image of a picture cannot be loaded, for instance when <code>resolvePictureSrc</code> refuses it. A picture of loaded data is left out of the drawing, and the event is fired once the other shapes are loaded.
        A picture added by <code>addShapes</code> or <code>updateShapes</code> stays in the drawing, without being drawn: <code>paint.getShape(shape.id)</code> tells which. The Editor shows an error message for it.
      </p>
      <Source language='typescript' code={`paint.registerEvent('pictureLoaded', () => upload(paint.getCurrentImage()))
paint.registerEvent('pictureLoadFailed', (shape: ShapeEntity<'picture'>, error: unknown) => {
  console.warn('Cannot load', shape.src, error)
})`} />

      <h2 id="Performance">Performance</h2>
      <p>
        The component calling <code>useReactPaint</code> never renders again because of the drawing: the components that read the state with <code>usePaintState</code> do, when the value they select changes.
        The gestures on the canvas (hover, drag, selection frame, pan, brush) are drawn without rendering the <code>Canvas</code> component.
      </p>
      <ul>
        <li>Select precise slices of the state: a component reading <code>state.history.canUndo</code> does not render while a shape is dragged, one reading <code>state.shapes</code> does</li>
        <li>When a selector builds an object or an array, give <code>shallowEqual</code> (or your own equality function), otherwise the component renders on each change of the state</li>
        <li>Read <code>state.interaction</code> only when you need it: it changes on each move of the pointer</li>
        <li>In event handlers, read the state with <code>paint.getState()</code> instead of subscribing to it</li>
      </ul>

  lineCap?: 'round' | 'butt' | 'square'
  // corners of a rectangle, a square, a polygon or a brush: 'round' by default
  lineJoin?: 'round' | 'bevel' | 'miter'
  // corners of a rectangle, a square, a picture or a polygon, in the units of the drawing: 0 by default, as large as
  // the sides allow. The ends of an open polygon stay sharp
  cornerRadius?: number
  closedPoints?: number
  // lines of a text in its box: 'left' by default. When its content changes, the box keeps the side of its alignment,
  // or its middle when centered
  textAlign?: 'left' | 'center' | 'right'
  // height of the lines of a text, in font sizes: 1 by default. Like in CSS, the letters are in the middle of their line,
  // and the box of the text is as high as its lines
  lineHeight?: number
  fontFamily?: string
  fontItalic?: boolean
  fontBold?: boolean
  // lines under and through the lines of a text, of its color
  fontUnderline?: boolean
  fontStrikethrough?: boolean
  // outline around the letters of a text, none by default, and its thickness around them in the units of the drawing: 2 by default
  outlineColor?: string
  outlineWidth?: number
}`} />

      <h3>ShapeInput and ShapePatch</h3>
      <p>
        <code>ShapeInput</code> is a shape given to <code>addShapes</code>, <code>resetCanvas</code> or <code>useReactPaint</code>: an <code>ExportedDrawableShape</code>, whose text can be given without its size.
        <code>ShapePatch</code> is given to <code>updateShapes</code>: the id of a shape and the fields to change, its type excepted.
      </p>
      <Source language='typescript' code={`const text: ShapeInput = { type: 'text', x: 0, y: 0, value: ['Hello'], fontSize: 24 }
const patch: ShapePatch = { id: 'rect_1', width: 200, style: { fillColor: 'red' } }`} />

        Type for defining custom tools. Extends base tool properties with shape-specific settings.

      <h3>ToolsSettingsType</h3>
      <p>
        Type-safe settings for each tool type. Settings vary by shape type:
      </p>
      <ul>
        <li><code>ToolsRectSettings</code> - Rectangle settings (includes lineJoin and cornerRadius)</li>
        <li><code>ToolsSquareSettings</code> - Square settings (includes lineJoin and cornerRadius)</li>
        <li><code>ToolsCircleSettings</code> - Circle settings</li>
        <li><code>ToolsEllipseSettings</code> - Ellipse settings</li>
        <li><code>ToolsLineSettings</code> - Line settings (includes arrow options and lineCap)</li>
        <li><code>ToolsBrushSettings</code> - Brush settings (includes lineJoin and lineCap)</li>
        <li><code>ToolsPolygonSettings</code> - Polygon settings (includes closedPoints, lineJoin, lineCap and cornerRadius)</li>
        <li><code>ToolsCurveSettings</code> - Curve settings (includes closedPoints and lineCap)</li>
        <li><code>ToolsTextSettings</code> - Text settings (includes font options, textAlign, lineHeight, fillColor for the background, fontUnderline, fontStrikethrough, outlineColor, outlineWidth, and fontSize: the font size of the new texts, which are as wide as their content, or 150 wide without it. Its max is optional)</li>
        <li><code>ToolsPictureSettings</code> - Picture settings (opacity, and the border: strokeColor, lineWidth and cornerRadius)</li>
        <li><code>ToolsTriangleSettings</code> - Triangle settings</li>
        <li><code>ToolsGroupSettings</code> - Group settings</li>
      </ul>

      <h2 id="Helpers">Helpers</h2>
      <p>Exported from the package root and from <code>@yorab/react-paint/canvas</code>, they are useful to build a custom editor:</p>
      <ul>
        <li><code>getSelectedShapes(selection)</code> - Returns the shapes of a selection, which can be a single shape or a group</li>
        <li><code>getSelectedShapesTools(selection, tools)</code> - Returns the tool matching the selection. For several shapes, it returns a tool whose settings are the ones shared by all the shapes</li>
        <li><code>DEFAULT_TOOLS</code> - Default drawing tools</li>
        <li><code>SELECTION_TOOL</code>, <code>MOVE_TOOL</code> - Selection and move tools, to give to <code>actions.selectTool</code></li>
        <li><code>ZOOM_LEVELS</code> - Levels of <code>actions.setZoom</code>, from <code>0.05</code> to <code>8</code>: every zoom stays between the first and the last one, to disable a button or to build a zoom menu</li>
        <li><code>shallowEqual(a, b)</code> - Equality function for <code>usePaintState</code> selectors building an object or an array</li>
      </ul>
