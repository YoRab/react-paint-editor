      <h2>Advanced Usage</h2>
      <p>
        For more control, you can configure the canvas size, initial shapes, and various options:
      </p>
      
     <Source language='typescript' code={`import { useEffect, useState } from 'react'
import { Canvas, Editor, useReactPaint, type DrawableShape } from '@yorab/react-paint'
import '@yorab/react-paint/react-paint.css'

function AdvancedPaintApp() {
  const [shapes, setShapes] = useState<DrawableShape[]>([])

  const paint = useReactPaint({
    width: 1920,
    height: 1080,
    shapes,
    options: {
      canGrow: true,
      canShrink: true,
      brushAlgo: 'quadratic',
      clearCallback: 'empty'
    }
  })

  // registerEvent returns the function that unregisters the listener
  useEffect(() => paint.registerEvent('dataChanged', data => setShapes(data.shapes)), [paint])

  return (
    <Editor paint={paint}>
      <Canvas paint={paint} />
    </Editor>
  )
}`} />
      
      <h2>Key Concepts</h2>
      
      <h3>useReactPaint Hook</h3>
      <p>
        The <code>useReactPaint</code> hook is the core of React Paint. It returns a handle, <code>paint</code>, to give to the <code>Editor</code> and <code>Canvas</code> components, or to <LinkTo title='React Paint/Custom editor' story='docs'>your own editor</LinkTo>.
        It keeps the same identity for the whole life of the component, and the component calling the hook does not render again when the drawing changes. The handle gives:
      </p>
      <ul>
        <li><code>actions</code> - Commands to act on the canvas: select a tool, undo, zoom, style the selected shapes...</li>
        <li><code>getState</code> and <code>subscribe</code> - The current state, and a way to be told of its changes</li>
        <li><code>registerEvent</code> - Function to listen to events (like <code>dataChanged</code>). It returns the function that stops listening</li>
        <li><code>unregisterEvent</code> - Function to stop listening to events</li>
        <li><code>resetCanvas</code> - Function to reset the canvas with new shapes</li>
        <li><code>getCurrentImage</code> - Function to export the canvas as a PNG image</li>
        <li><code>getCurrentData</code> - Function to get the current state of the canvas</li>
        <li><code>scopeRef</code> - Callback ref to set on the root element of a custom editor, so that the keyboard shortcuts also work from its toolbar</li>
      </ul>

      <h3>Reading the state</h3>
      <p>
        <code>usePaintState(paint, selector?, isEqual?)</code> reads the state during a render, and renders the component again only when the selected value changes.
        When the selector builds an object or an array, give <code>shallowEqual</code> as third argument. Under the <code>Editor</code> or a <code>PaintProvider</code>, any component can get the handle with <code>usePaint()</code>.
      </p>
      <Source language='typescript' code={`import { shallowEqual, usePaint, usePaintState } from '@yorab/react-paint'

const UndoButton = () => {
  const paint = usePaint()
  const canUndo = usePaintState(paint, state => state.history.canUndo)
  return <button disabled={!canUndo} onClick={paint.actions.undo}>Undo</button>
}

const { shapes, selectedShapes } = usePaintState(paint, state => ({ shapes: state.shapes, selectedShapes: state.selectedShapes }), shallowEqual)`} />
      
      <h3>Editor Component</h3>
      <p>
        The <code>Editor</code> component provides the toolbar with all drawing tools, settings, and controls. It must wrap the <code>Canvas</code> component.
      </p>
      
      <h3>Canvas Component</h3>
      <p>
        The <code>Canvas</code> component is where all the drawing happens. It handles mouse/touch interactions, rendering, and shape manipulation.
      </p>

      <h3>Modules</h3>
      <p>
        The library is made of two independent modules: <strong>canvas</strong> (<code>Canvas</code> and <code>useReactPaint</code>) and <strong>editor</strong> (<code>Editor</code>).
        When you don't use <code>Editor</code>, it is removed from your bundle. Each module can also be imported separately, only the editor has a stylesheet:
      </p>
      <Source language='typescript' code={`import { Canvas, useReactPaint } from '@yorab/react-paint/canvas'

import { Editor } from '@yorab/react-paint/editor'
import '@yorab/react-paint/editor/editor.css'`} />
      <p>
        To build your own editor, read the state with <code>usePaintState</code>, act on the canvas with <code>paint.actions</code>, and set <code>paint.scopeRef</code> on its root element. Used alone, the <code>Canvas</code> needs nothing more.
        See the <LinkTo title='React Paint/Custom editor' story='docs'>Custom editor</LinkTo>, <LinkTo title='React Paint/Canvas only' story='docs'>Canvas only</LinkTo> and <LinkTo title='React Paint/External toolbar' story='docs'>External toolbar</LinkTo> examples.
      </p>
      
      <h2>Configuration Options</h2>
      <p>
        React Paint offers extensive configuration through the <code>options</code> parameter:
      </p>
      <ul>
        <li><strong>Canvas Size</strong> - Set <code>width</code> and <code>height</code> for fixed-size canvas, or use <code>size: 'infinite'</code> for unlimited canvas</li>
        <li><strong>Zoom & Pan</strong> - Enable with <code>canZoom: 'always'</code> and control growth/shrink with <code>canGrow</code> and <code>canShrink</code></li>
        <li><strong>Grid</strong> - Add a grid overlay with <code>grid: 20</code> (size in pixels)</li>
        <li><strong>Features</strong> - Toggle export, save/load, picture upload, frame selection, and more</li>
        <li><strong>Brush Algorithm</strong> - Choose between <code>'simple'</code> or <code>'quadratic'</code> for brush rendering</li>
        <li><strong>Clear Behavior</strong> - Set what happens when clearing: <code>'empty'</code>, <code>'defaultShapes'</code>, or a custom function</li>
        <li><strong>Debug</strong> - Enable <code>options.debug: true</code> to log shape selection and hit-testing to the browser console</li>
      </ul>

      <h2>Event Handling</h2>
      <p>
        React Paint emits events that you can listen to for state synchronization:
      </p>
      
     <Source language='typescript' code={`useEffect(() => {
  const onDataChanged = (data: StateData, source: 'user' | 'remote') => {
    // data.shapes contains all current shapes
    // source indicates if the change came from user interaction or remote update
    console.log('Canvas data changed:', data)
    setShapes(data.shapes)
  }

  // returns the function that unregisters the listener
  return paint.registerEvent('dataChanged', onDataChanged)
}, [paint])`} />

// Export with default view (canvas dimensions, no zoom)
const imageUrl1 = paint.getCurrentImage('defaultView')

// Export with current zoom and offset
const imageUrl2 = paint.getCurrentImage('currentZoom')

// Export fitting all shapes
const imageUrl3 = paint.getCurrentImage('fitToShapes')

// Use the data URL (e.g., download or display)

link.download = 'my-drawing.png'
link.href = imageUrl1
link.click()`} />
